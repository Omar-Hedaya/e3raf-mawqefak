# 🎓 اعرف موقفك (E3raf Mawqefak)

تطبيق ويب شامل وسريع (PWA) مصمم خصيصاً لطلاب الجامعات المصرية وكليات الهندسة لحساب درجات أعمال السنة، الدرجة المطلوبة في الامتحان النهائي (Final) لكل تقدير، متابعة الغياب ومواعيد الامتحانات، وحساب المعدل التراكمي (GPA) بدقة وسهولة.

---

## ✨ المميزات الرئيسية

- **📊 حساب درجات أعمال السنة بدقة:**
  - دعم التوزيعات المختلفة (40/60، 30/70، 50/50، أو توزيع مخصص).
  - تقسيمة تفصيلية تشمل (الميدتيرم الأول، الميدتيرم الثاني، الشيتات/العملي، البونص، والكويزات).
  - خيار جمع كل الكويزات تلقائياً أو اختيار أحسن `N` كويزات، مع إمكانية تعليم أي بند كـ **"لسه مامتحناش"**.
  - تسجيل محطات تطور درجاتك في المادة على مدار الترم.

- **🎯 محاكي الفاينل وتخصيص الأهداف:**
  - حساب فوري للدرجة المطلوبة في الفاينل للنجاح الصافي أو لتحقيق الامتياز (`A-` / `A`) مع مراعاة الحد الأدنى للفاينل ومحاكاة درجات الرأفة.
  - محاكي تفاعلي للسيناريوهات (سلايدر + إدخال رقمي مباشر) لمعرفة تقديرك النهائي المتوقع.
  - تخصيص هدف محدد (نسبة مئوية، تقدير موجب أو سالب مثل `A-` و `B-`، أو نقاط GPA).
  - إمكانية تعديل لائحة التقديرات والـ GPA بالكامل لتناسب لائحة أي كلية.

- **📅 رادار الامتحانات وعدّاد الغياب:**
  - ترتيب تلقائي لكل المواعيد والامتحانات القادمة حسب الأولوية ودرجة الخطورة.
  - تصدير جدول الامتحانات والمواعيد كملف تقويم قياسي (`.ics`) لإضافته لتقويم الموبايل مع تنبيهات.
  - عدّاد غياب ذكي يحسب الرصيد المتبقي وينبّهك قبل الوصول لنسبة الحرمان.

- **🖨️ تصدير كشوف درجات رسمية (PDF) والمشاركة:**
  - تصدير كشوف درجات رسمية جاهزة للطباعة بـ 4 أنماط مختلفة (الميد الأول فقط، الميد الثاني فقط، أعمال السنة، أو التقرير الشامل بالـ GPA).
  - إنشاء كارت مشاركة مصمم للستوري والجروبات.
  - مشاركة تقسيمة أي مادة أو حزمة الترم بالكامل مع الدفعة عبر رابط مباشر (`URL Hash`).

- **⚡ تجربة استخدام متكاملة:**
  - حفظ تلقائي للبيانات محلياً (`LocalStorage`) بدون الحاجة لتسجيل دخول.
  - دعم الوضع الليلي والنهاري (Dark / Light Mode).
  - يعمل بدون إنترنت كـ تطبيق ويب تقدمي (`PWA`) قابل للتثبيت على الشاشة الرئيسية.

---

## 🚀 طريقة الاستخدام

1. افتح الرابط المباشر للتطبيق من أي متصفح على الموبايل أو الكمبيوتر.
2. أدخل بياناتك (الاسم، رقم الجلوس، التخصص، والفرقة) لتظهر تلقائياً في كشوف الطباعة.
3. أضف مواد الترم وحدد درجات أعمال السنة، وسيقوم التطبيق بحساب موقفك فوراً.
4. يمكنك تثبيت التطبيق على شاشة الموبايل من قائمة المتصفح (**Add to Home Screen**).

---

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3** (تصميم متجاوب بالكامل مع تنسيقات طباعة مخصصة `@media print`)
- **Vanilla JavaScript** (بدون أي مكتبات خارجية لضمان أقصى سرعة وأداء)
- **Canvas API** (لتوليد كروت المشاركة)
- **PWA & LocalStorage** (للعمل أوفلاين وحفظ البيانات محلياً)
